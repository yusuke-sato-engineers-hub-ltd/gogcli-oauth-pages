gogcli プライバシーポリシー

gogcli は、開発者本人が自身の Google アカウントに対してのみ使用する個人用ツールです。

  • gogcli は、利用者が許可した範囲で Google API を通じて Google ユーザーデータにアクセスします。
  • 取得したデータと OAuth トークンは利用者の端末内でのみ処理・保存し、開発者が管理するサーバーへ送信しません。
  • Google ユーザーデータを第三者に販売、譲渡、共有しません。広告目的には使用しません。
  • gogcli による Google API から取得した情報の使用と他アプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に従います。
  • アクセス権は Google アカウントのサードパーティ アクセス設定 からいつでも取り消せます。端末内のデータは利用者が削除できます。

gogcli Privacy Policy

gogcli is a personal tool used only by its developer with the developer's own Google accounts.

  • gogcli accesses Google user data through Google APIs only within the scopes the user authorizes.
  • Retrieved data and OAuth tokens are processed and stored only on the user's local machine and are not sent to any server operated by the developer.
  • Google user data is not sold, transferred, or shared with third parties, and is not used for advertising.
  • gogcli's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from Google Account third-party access settings. Local data can be deleted by the user.
